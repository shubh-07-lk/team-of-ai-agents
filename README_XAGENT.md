# L3AGI → XAgent Integration
This folder contains a minimal setup replacing LangChain REACT Agent with XAgent.

## Files
- xagent_adapter.py → Adapter to bridge XAgent into L3AGI
- conversational_xagent.py → Replacement for conversational agent
- dialogue_agent_with_tools_xagent.py → Replacement with tools
- test_xagent.py → Basic tests
- sample_run.py → Quick demo

## Run
```bash
pip install -r requirements.txt
python sample_run.py
```
